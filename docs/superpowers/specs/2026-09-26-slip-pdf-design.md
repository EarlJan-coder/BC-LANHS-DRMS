# Slip PDF Redesign — Match the Certificate Design

**Date:** 2026-09-26
**Status:** Approved (design), pending implementation plan

## Goal

The document request slip PDF (downloaded from the student/alumni portal) is currently a plain black-text dump. Redesign it to use the same visual design as the certificate PDF: letterhead, brand colors, bordered panels, signature lines, and a QR code.

## Scope

- **In scope:** new shared PDF brand module; redesign of `generateRequestSlipPdf`; refactor of `certificates.ts` to import shared helpers.
- **Out of scope:** changing slip data fields, API routes, DB schema, the certificate's visual output, or any UI components.

## Decisions (confirmed with user)

1. **Full certificate treatment** — letterhead, bordered panels, status badge, signature lines, QR code, A4 page.
2. **QR encodes the request page URL** — `${appUrl()}/student/requests/${request.id}`, caption "Scan to track request".
3. **Same fields as today** — tracking number, student, document type, purpose, requested date, status, school year needed, grade level needed, remarks. No registrar/blockchain fields.

## Approach

**Approach A (approved):** extract shared design code into `src/lib/services/pdf-brand.ts`; both `certificates.ts` and `document-requests.ts` consume it. Single source of truth for brand rendering.

## Design

### 1. Shared module: `src/lib/services/pdf-brand.ts`

Moved from `certificates.ts` with identical values (certificate output unchanged):

- **Tokens:** `LOGO_PATH`, `PAGE_WIDTH = 595.28`, `PAGE_HEIGHT = 841.89` (A4), `BRAND_RED = rgb(0.725, 0.109, 0.109)`, `DARK_TEXT = rgb(0.067, 0.094, 0.153)`, `MUTED_TEXT = rgb(0.42, 0.45, 0.5)`, `LIGHT_BORDER = rgb(0.9, 0.9, 0.9)`.
- **Text helpers:** `drawCenteredText`, `drawWrappedText` (signatures unchanged).
- **Layout helpers:**
  - `embedSchoolLogo(pdf)` — PNG embed with `null` fallback on failure.
  - `drawDocumentHeader(page, logo, regular, bold)` — logo 72×72 at (58, 742) or red circle "LANHS" fallback; DepEd/school letterhead block; 1.5pt `BRAND_RED` rule at y=720 from x=50 to x=545.
  - `drawSignatureLine(page, from, to, label, x, regular)` — hairline `DARK_TEXT` rule at y=102 plus muted 9pt caption (parameterized so slip and certificate place their own labels).
  - `embedQrCode(pdf, dataUrl)` helper for QR PNG embedding (wraps `QRCode.toDataURL` + `embedPng`).
- `appUrl()` moves here too (still `process.env.NEXT_PUBLIC_APP_URL ?? "http://localhost:3000"`).

`certificates.ts` imports these and deletes local duplicates. Its `drawCertificateFooter` stays local (certificate-specific captions: "Scan to verify", authenticity note) but calls shared helpers where they fit. Result: certificate PDF renders identically.

### 2. Slip layout: `generateRequestSlipPdf` (`document-requests.ts:118-165`)

A4 page (595.28 × 841.89) via shared tokens. Top to bottom:

1. **Letterhead** — `drawDocumentHeader` (shared).
2. **Title** — "Document Request Slip", centered, `BRAND_RED`, bold 18pt (~y=680); subtitle "Official receipt of document request" muted 9pt beneath.
3. **Meta row** — Tracking No. (left, x=50) and Requested date (right), 9–10pt, muted labels + dark values (mirrors certificate meta row).
4. **Info panel** — white rectangle, `LIGHT_BORDER` 0.8pt border: Student Name, LRN, Grade Level Needed, School Year Needed. Labels muted 8pt, values dark 10pt.
5. **Details panel** — second bordered rectangle: Document Type, Purpose (wrapped via `drawWrappedText`), Remarks (wrapped), and a **status badge**: small filled rectangle (pdf-lib has no rounded-corner support) in the badge palette from `REQUEST_STATUSES` (`src/lib/constants.ts:13-22`), white bold 9pt label centered in the rectangle. Mapping: pending → amber, under_review → sky, approved → emerald, rejected → red, processing → purple, ready_for_pickup → teal, claimed → slate, cancelled → zinc (use the `-700` shade as fill). Unknown status → neutral gray.
6. **Signature lines** — "Requested by" (left) and "Registrar" (right) using shared `drawSignatureLine`.
7. **QR code** — 68×68 at (465, 132) encoding `${appUrl()}/student/requests/${request.id}`; caption "Scan to track request" `BRAND_RED` 8pt; plain URL 7pt muted at bottom-left; note "This QR code opens the request status page." muted 8pt.
8. **Footer note** — "Generated by LANHS DRMS · This slip is system-generated and does not require a signature to be valid." muted 8pt, bottom-left.

### 3. Data flow

Unchanged: `GET /api/document-requests/[id]/slip` → `generateRequestSlipPdf(id)` → `getDocumentRequestView(id, true)` → PDF bytes. Only rendering internals change.

### 4. Edge cases

- **Missing logo:** header falls back to red circle badge (existing certificate fallback behavior).
- **Missing optional fields** (purpose, remarks, grade level, school year): skip the row instead of printing "undefined".
- **Unknown status:** neutral gray badge.
- **Invalid ID:** keep existing `throw new Error("Document request not found.")`; route already maps thrown errors to a JSON error response.

## Verification

1. Typecheck: `npx tsc --noEmit` (plus any lint script in `package.json`).
2. `GET /api/certificates/{id}/pdf` — certificate renders identically after extraction.
3. `GET /api/document-requests/{id}/slip` — slip shows the new design; open both PDFs and eyeball: letterhead, colors, panels, badge, signatures, QR resolves to the request page.
